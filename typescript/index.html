Quick Start & Integration

三分鐘嵌入你的專案

同時提供完整 TypeScript 模組、按需 Tree-shaking 子路徑導出、免建置 ESM / IIFE 雙 CDN，以及 6 大主流前端框架零配置資產外掛。

src/main.ts 
import {
  initAvatarBot,
  type AvatarBotOptions,
  type AiAvatarWidget
} from '@ai-avatar-bot/sdk';
import '@ai-avatar-bot/sdk/style.css';

const options: AvatarBotOptions = {
  container: document.getElementById('avatar-container'),
  startMode: '3d',          // '2d' (Live2D) | '3d' (VRM)
  fitMode: 'half',          // 'half' (半身特寫) | 'full' (全身)
  gender: 'female',
  avatarMode: 'assistant',  // 'assistant' | 'companion' | 自訂模式鍵名
  webLlmModel: 'Hermes-3-Llama-3.1-8B-q4f32_1-MLC',
  webLlmFallbackModel: 'Qwen2.5-1.5B-Instruct-q4f16_1-MLC',
  enableOomFallback: true,
  enableMemory: true
};

const widget: AiAvatarWidget = await initAvatarBot(options);

Modular Multi-Engine Design

六大高內聚、低耦合引擎架構

從原版單體腳本全面重構為嚴格型別化的多引擎管線，任何子系統皆可獨立替換或以無頭模式（Headless Mode）整合至既有設計系統。

🧠

大腦與記憶引擎

@ai-avatar-bot/sdk/brain
  • 遠端 AI Provider ➔ 瀏覽器 WebGPU WebLLM ➔ Bigram 關鍵字檢索三層自動降級
  • 支援 <think> 雙軌思考鏈串流解析與顯存不足（OOM）兩階段平滑保底
  • 滑動視窗與背景滾動摘要壓縮，內建 <reference_data> 提示詞資料圍欄防禦
🗣️

全雙工語音與對嘴引擎

@ai-avatar-bot/sdk/speech
  • 整合 Web Speech STT 與微軟神經網路 TTS（異常時無縫降級跨平台原生語音）
  • 支援說話中即時語音插話打斷（Barge-in）與陪伴模式連續對話迴圈
  • 即時計算音訊頻譜振幅驅動模型嘴型開合（Real-time Lip Sync）
🎭

2D / 3D 雙外觀渲染引擎

@ai-avatar-bot/sdk/skin
  • 同時支援 Pixi.js Live2D 與 Three.js VRM，運行時可一鍵熱切換
  • 內建 3D VRMA 呼吸待機池、性別偶發小動作、說話動作池與游標視線追蹤
  • 支援四層語意動作解析與本地 .vrm 拖放即時換裝
🛠️

Function Calling 工具引擎

@ai-avatar-bot/sdk/tools
  • 支援純前端規則秒配（client）、AI 語意調用（ai）與雙軌混合（hybrid）
  • 內建 JSON Schema 必填參數追問補齊與型別驗證
  • 敏感操作支援 Human-in-the-loop 授權確認卡片與逾時保護

FAQ & Asset Licensing

環境提醒、隱私流向與第三方資產授權

正式導入商業專案前，請詳閱瀏覽器環境建議、資料隱私邊界以及內建範例模型之版權規範。

💻 瀏覽器與硬體環境建議（推薦 Chrome / Edge 桌機版）

建議使用最新版桌面端 Chrome 或 Edge 瀏覽器以獲得最完整的 Web Speech 語音辨識與 WebGPU 端側模型加速體驗；Safari 18+ 與行動裝置瀏覽器亦支援 2D/3D 渲染與文字／知識庫對話。

即使不點擊控制列的「🧠」下載 WebLLM 模型（首次約需快取 1GB～4GB 權重），虛擬人依然能透過內建高速檢索大腦秒速回答問題！

🔐 隱私保護與資料流向說明

100% 留在本機：WebLLM 端側推論與多輪對話記憶（localStorage）全程在您的瀏覽器記憶體中運算與儲存，絕不主動上傳外部伺服器；對麥克風說「忘記我」或點擊歷史面板「清除」即可清空紀錄。

外部服務邊界：瀏覽器原生語音辨識（STT）會將音訊交由瀏覽器廠商雲端（如 Google）辨識；語音合成（TTS）優先經由輕量 Serverless Proxy（/api/tts），離線或未配置時自動降級為 100% 本機原生語音合成。

🔌 如何在本地開發串接 Ollama / OpenAI / Claude 等遠端 AI？

在公開的 Vercel 展示站中，為避免觸發瀏覽器區域網路（Loopback）權限彈窗，預設將 aiProviderAutoPing 設為 'manual'。若您在本地執行 yarn dev，展示頁會自動透過 Vite 代理探活本機 Ollama。

在自有專案中只需設定 enableAiProvider: true、aiProviderBaseUrl 與不可變標頭 aiProviderHeaders，即可無縫對接 Ollama、vLLM、OpenAI、Anthropic 或自建 API Gateway。

⚠️ 商業部署重要提醒：@ai-avatar-bot/sdk 之自有原始程式碼採用 MIT License 開源；但套件內附帶供技術展示用的第三方運行時核心與範例角色模型不屬於 MIT 授權範圍。商業上線前請務必透過 modelUrl 或 vrmUrl 替換為您自有或合法取得授權的模型資產。
